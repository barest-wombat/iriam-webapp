# IRIAMランク管理ツール

IRIAM のランク管理を手元で試算するための静的 PWA です。現在ランク、ランクスコア、公式表示の「あと○日」、スキップパス枚数、日別の予定ポイントを入力すると、将来のランク推移と予測カードを確認できます。

## エンドユーザー向け

### 主な機能

- 現在ランク、ランクスコア、公式表示の「あと○日」、スキップパス枚数の入力
- 今日から未来30日分の予定入力
- ランクアップ、ランクダウン、スキップ使用、週次スキップパス付与を含むシミュレーション
- ライト、ダーク、デバイス連動のテーマ切り替え
- 入力内容の `localStorage` 保存
- Service Worker による PWA キャッシュ

### ファイル構成

- `index.html`: 画面構造
- `style.css`: テーマ、フォーム、テーブル、予測カード、モバイル表示のスタイル
- `script.js`: 初期化、入力保存、予定表生成、DOM 非依存のランク計算、結果表示
- `sw.js`: PWA 用 Service Worker
- `manifest.json`: PWA マニフェスト
- `icons/`: PWA アイコン

### データ保存

入力内容はブラウザの `localStorage` に保存されます。サーバーや外部 API には送信されません。

画面右上のリセットボタンを押すと、このアプリが保存した入力データを削除します。

## 開発者向け

### ローカル起動

このリポジトリはビルド工程を持たない静的 Web アプリです。ローカル確認では、リポジトリ直下で静的サーバーを起動してください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。

`index.html` を直接開いても画面表示はできますが、Service Worker の確認には HTTP 配信が必要です。

### ブラウザ確認

表示や挙動を変えた場合は、ローカルサーバーとデプロイ先の両方を確認してください。

- ローカル: `http://localhost:8000/`
- デプロイ先: `https://barest-wombat.github.io/iriam-webapp/`

確認では、画面が表示されるだけでなく、`style.css`、`script.js`、`manifest.json` が想定 URL から読み込まれていること、ブラウザのコンソールにエラーが出ていないこと、「計算」ボタンで結果が描画されることを見ます。

### PWA キャッシュの注意

`sw.js` は静的アセットをキャッシュ優先で返します。HTML、CSS、JavaScript、マニフェスト、アイコンを変更した場合は、`sw.js` の `CACHE` 名を更新して、既存キャッシュが置き換わるようにしてください。
